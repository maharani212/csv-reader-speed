# csv-reader-speed

A faster drop-in replacement for csv-reader 1.0.0 that matches the reference exactly on every case.

Built for the [make.fun bounty "Read broken CSV files faster, 21 November 2026"](https://make.fun/bounty/csv-reader-speed-01-run-20261121). Identical output to the reference on 77/77 edge cases and 6/6 practice cases, at ~3.22x the reference speed.
